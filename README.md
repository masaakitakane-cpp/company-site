# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア受託開発会社「スカイライン・テクノロジーズ」の1ページ企業サイトです。

## 概要

- 建築ブループリント(設計図)をモチーフにしたデザイン
- サービス紹介、開発プロセス、導入実績、お知らせ、お問い合わせフォームなどを掲載
- ライト/ダーク両テーマに対応(OS設定に追従)
- HTML/CSS/JavaScriptのみで構成された静的サイト(ビルド不要)

## ファイル構成

```
company-site/
├── index.html   # サイト本体(このファイル1つで完結)
└── README.md
```

## ブラウザで開く手順

1. リポジトリをクローンまたはダウンロードする
2. `index.html` をブラウザにドラッグ&ドロップ、またはダブルクリックして開く

ターミナルから開く場合は以下のコマンドを実行してください。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

ローカルサーバー経由で確認したい場合は、任意の静的サーバーを起動してアクセスしてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
